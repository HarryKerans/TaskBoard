# TaskBoard

A task dashboard that merges your Amazon Alexa TODO list with locally-stored tasks backed by SQLite. Built with a **FastAPI** backend and a **React** (TypeScript) frontend.

## Features

- Authenticates with Amazon using email/password (from `.env`) + a one-time OTP entered in the UI
- Pulls your Alexa TODO list items via the Amazon Echo API
- Stores and displays local tasks with `high / medium / low` priority in SQLite
- Deduplicates Alexa and local tasks by title (case-insensitive)
- Session persistence — refreshing the page skips the login screen if a session is still alive
- Can be deployed as a Home Assistant add-on via Docker

## Environment Variables

Create a `.env` file in the project root:

```dotenv
REACT_APP_AMAZON_EMAIL=your.amazon@email.com
REACT_APP_AMAZON_PASSWORD=yourAmazonPassword
REACT_APP_AMAZON_COUNTRY=com          # or co.uk, de, etc.
DATABASE_PATH=./tasks.dev.db          # local dev path (relative to backend/); Docker/HA uses /data/tasks.db
```

> The `.env` file is loaded by the backend at startup. The frontend never reads credentials — it only sends the OTP entered by the user.
>
> `DATABASE_PATH` is relative to the directory you run uvicorn from (`backend/`), so `./tasks.dev.db` creates `backend/tasks.dev.db`. In Docker/HA the path is overridden to `/data/tasks.db` on a persistent volume.

## Development

Two servers run in parallel in dev mode: the React dev server (port 3000) and the FastAPI backend (port 8000). The React app proxies API requests to the backend automatically.

### 1. Install frontend dependencies

```bash
cd task_board/frontend
npm install
```

### 2. Set up the backend

```bash
cd task_board/backend
uv sync          # creates .venv and installs all dependencies
```

### 3. Start the backend

```bash
cd task_board/backend
.venv/bin/uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

### 4. Start the frontend (separate terminal)

```bash
cd task_board/frontend
npm start
```

Open [http://localhost:3000](http://localhost:3000). The React dev server proxies `/auth/*`, `/lists/*`, and `/api/*` to `http://localhost:8000`.

### API Endpoints (quick reference)

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/auth/status` | Check if a session is active |
| `POST` | `/auth/login` | Log in (`{ "otp": "123456" }`) |
| `GET` | `/lists` | Fetch Alexa lists |
| `GET` | `/lists/{listId}/items` | Fetch items in a list |
| `GET` | `/api/tasks` | List local SQLite tasks |
| `POST` | `/api/tasks` | Create a task (`{ "title": "...", "priority": "high" }`) |
| `GET` | `/api/health` | Health check + DB info |

## Production / Docker

Build and run everything in a single container:

```bash
docker build -t taskboard .
docker run -p 8000:8000 --env-file .env taskboard
```

The container serves the compiled React app as static files from FastAPI at [http://localhost:8000](http://localhost:8000).
